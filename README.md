# React Grid Layout Demo

This project is a simple **React.js layout demo** that showcases how to build a responsive page using **CSS Grid**.  
The layout includes a header, three small content boxes, a sidebar, a main content area, and a footer, all arranged using modern layout techniques.

## 🧩 Features

- Header spanning the full width at the top  
- Three equal small boxes in the second row  
- Sidebar aligned to the right side  
- Main content area below the small boxes  
- Footer spanning the full width at the bottom  
- Built with **React** (`App.jsx`, `main.jsx`) and **CSS Grid** (`App.css`, `index.css`)

## 🛠 Tech Stack

- **React.js** (Vite / React setup)
- **JavaScript (ES6+)**
- **CSS Grid & Flexbox**
- Project structure:
  - `src/App.jsx` – main layout component
  - `src/App.css` – styles for the layout boxes
  - `src/index.css` – global styles
  - `src/main.jsx` – React entry point
  - `src/assets/` – static assets (if any)
